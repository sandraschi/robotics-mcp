# Blender script repository

Blender Python scripts used with the Robotics MCP Blender integration: procedural models, environments, and utilities.

## Directory structure

```
scripts/
├── index.json          # Script catalog and metadata
├── robots/            # Robot models and components
├── architecture/      # Buildings and structures
├── tools/             # Modeling utilities
├── environments/      # Terrain and environmental models
└── README.md          # This file
```

## Usage with Robotics MCP

### List available scripts

```python
await list_blender_scripts()
# Returns: {"robots": ["moorebot_scout"], "architecture": [], ...}
```

### Run a repository script

```python
await execute_repository_script(
    category="robots",
    script_name="moorebot_scout",
    output_path="D:/models/scout.fbx",
    parameters={"dimensions": {"length": 0.15, "width": 0.12}}
)
```

### Direct execution

```python
script_path = "scripts/robots/moorebot_scout.py"
with open(script_path, 'r') as f:
    script = f.read()

await robot_model(
    operation="execute_script",
    script=script,
    output_path="D:/models/scout.fbx"
)
```

## Contributing scripts

1. Generate or write a Blender Python script and test it in Blender.
2. Add metadata in the docstring.
3. Register the script in `index.json`.
4. Update this file if you add categories or change conventions.

## Naming

- Filenames: `snake_case.py`
- Blender objects: `PascalCase` where appropriate (e.g. `Scout_Body`)

## Compatibility

- Blender 3.0+ (prefer current LTS)
- Prefer `bpy.ops` patterns that match the rest of the repo
- Parameterize dimensions where it helps reuse

## Categories and tags

- **robots**: wheeled, legged, manipulators, drones
- **architecture**: historic, modern, industrial, residential
- **tools**: utilities, generators, modifiers
- **environments**: terrain, vegetation, weather
